Localizacion Argentina - Monotributista
=======================================

Meta modulo para instalar en un solo paso un paquete argentino reducido para
instancias de monotributistas.

Incluye:

* Localizacion contable argentina base
* Bancos argentinos
* AFIP Web Services
* Factura Electronica AFIP
* Padron AFIP / actualizacion de partners
* Datos extra de partners argentinos
* Base fiscal por comprobante con ``account_move_tax``

No incluye a proposito:

* Recibos multipago
* Retenciones
* Libro IVA
* IVA Digital
* Reportes de retenciones
* Percepciones y extras ampliados
