Localizacion Argentina - Instalador Full
========================================

Meta modulo que extiende ``l10n_ar_installer`` para instalar en un solo paso
funcionalidades argentinas adicionales que solemos usar en proyectos mas
completos.

Incluye ademas del perfil de responsable inscripto:

* Percepciones de ventas
* Padron ARBA
* Impuestos de compras
* QR fiscal argentino

Pensado para instancias donde queremos levantar el stack argentino mas
completo posible sin incluir modulos que hoy tienen dependencias externas o
faltantes dentro de este repositorio.
